# Aurora-Lens Publication Corpus

This archive contains the exact files currently deposited in nineteen Zenodo records associated with Margaret Stokes and the Aurora-Lens research record, reconstructed on 27 August 2026.

## Organisation

Each directory under `records/` is named with its Zenodo record number and contains:

- `files/`: the deposited files, retaining their exact Zenodo filenames;
- `zenodo-record.json`: the public Zenodo metadata returned by the records API; and
- `MD5SUMS`: the checksums published by Zenodo for those files.

`MANIFEST.tsv` provides a single index of every deposited file, its record, DOI, title, size and Zenodo MD5 checksum. `SHA256SUMS` supplies an additional checksum inventory for this assembled corpus.

## Maintained Unresolved State

Record `22112413` is the current version of *The Maintained Unresolved State: Priority Record and Documented Chronology*. Its complete seventeen-file evidence bundle is preserved under `records/22112413/files/`. It has not been reduced to the principal Markdown record or evidence manifest.

The stable concept DOI is `10.5281/zenodo.22110553`. Version 1 is record `22110554`; current version 2 is record `22112413`.

## Scope

This is a publication corpus, not a complete public Aurora-Lens repository. It does not contain private source code, patent specifications, filing records, internal correspondence or files recovered from a personal computer. Superseded Zenodo versions are documented in the publication catalogue but are not duplicated here when a current version exists.
