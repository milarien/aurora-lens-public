# Procurement Decision Standard v1 (Superseded)

Status: superseded by v2.  
Effective date: 2024-01-01.

## Approval requirement (v1)

A procurement request requires **manual compliance review** when total contract value is **50000 USD or more**.

## Supporting checks

- Vendor identity verification is required.
- Security questionnaire is required for software vendors.
- Financial due diligence must be recorded before approval.
