# Procurement Decision Standard v2 (Governing)

Status: active.  
Effective date: 2025-07-01.

This document **supersedes Procurement Decision Standard v1 in full**.

## Approval requirement (v2)

A procurement request requires **manual compliance review** when total contract value is **75000 USD or more**.

## Additional requirement introduced in v2

For software vendors, a data-handling attestation is mandatory before final approval.

## Interpretation rule

If v1 and v2 differ, v2 governs.
